# ADR-002: 화재/연기 감지에 YOLOv11n + NCNN 선택

## 상태

**Accepted** (2025-06)

## 맥락

엣지 디바이스(Raspberry Pi 5)에서 USB 카메라 영상을 실시간으로 분석하여 화재(fire)와 연기(smoke)를 감지해야 한다. 모델 선택 시 고려해야 할 제약 조건:

1. **추론 속도**: 실시간 감지를 위해 프레임당 100ms 이내 추론 필요
2. **하드웨어**: Raspberry Pi 5 (ARM Cortex-A76, GPU 없음). CUDA/GPU 가속 불가
3. **정확도**: 오탐(False Positive)이 과도하면 불필요한 알림 발생
4. **모델 크기**: 엣지 디바이스의 저장 공간과 메모리 제약

### 후보 모델 비교

| 모델     | 파라미터 수 | RPi5 추론 속도 (NCNN) | mAP@0.5 (FASDD_CV) |
| -------- | ----------- | --------------------- | ------------------ |
| YOLOv11n | 2.6M        | ~78.5ms               | 87.1%              |
| YOLOv11s | 9.4M        | ~180ms                | 89.2% (추정)       |
| YOLOv11m | 20.1M       | ~400ms+               | 91.0% (추정)       |
| YOLOv8n  | 3.2M        | ~85ms                 | 84.5% (추정)       |

## 결정

**YOLOv11n 모델을 NCNN 포맷으로 변환하여 사용**한다.

### 선택 근거

1. **추론 속도**: RPi5에서 78.5ms/프레임으로 약 12.7 FPS 달성. 실시간 감지 기준(10 FPS 이상) 충족
2. **정확도**: FASDD_CV 데이터셋 기준 mAP@0.5 87.1%로 화재/연기 감지에 충분한 성능
3. **NCNN 최적화**: Tencent의 NCNN 엔진은 ARM CPU에 최적화되어 GPU 없이도 효율적 추론 가능
4. **FP16 양자화**: NCNN 변환 시 FP16 Half Precision 적용으로 모델 크기 50% 감소 + 정규화 효과로 오히려 mAP 소폭 상승

### NCNN 선택 이유

| 추론 엔진    | ARM 최적화      | GPU 불필요   | Python SDK       | 모델 크기 |
| ------------ | --------------- | ------------ | ---------------- | --------- |
| **NCNN**     | ARM NEON 최적화 | O            | Ultralytics 내장 | 최소      |
| ONNX Runtime | 보통            | O            | O                | 보통      |
| TFLite       | ARM 최적화      | O            | O                | 보통      |
| TensorRT     | CUDA 최적화     | X (GPU 필수) | O                | 보통      |

## 대안 분석

### YOLOv11s — 기각

- mAP 약 2%p 향상되나 추론 속도가 180ms (5.5 FPS)로 실시간 기준 미달
- 화재 감지는 속도가 더 중요 (감지 지연 = 대응 지연)

### YOLOv8n — 기각

- 추론 속도는 유사하나, YOLOv11n이 동일 모델 크기 대비 mAP 약 2.6%p 우위
- YOLOv11의 개선된 C3k2 블록과 SPPF로 작은 객체(초기 연기) 감지 성능 향상

### 클라우드 추론 (서버 전송 후 감지) — 기각

- 네트워크 지연(RTT 50~200ms) + 서버 추론 시간 추가
- 네트워크 장애 시 화재 감지 불가 → 안전 시스템에서 치명적
- 엣지 추론은 네트워크 독립적으로 동작하여 안정성 확보

## 결과

### 긍정적

- Raspberry Pi 5에서 12.7 FPS 실시간 화재 감지 달성
- NCNN FP16 변환 후 모델 크기 5.2MB로 엣지 디바이스 저장 부담 최소
- 네트워크 의존성 없이 로컬에서 감지 가능 → 안전성 극대화

### 부정적

- 고해상도(1280px) 입력 시 추론 속도 저하 → 640px로 입력 크기 제한
- 야간/저조도 환경에서 정확도 저하 가능 → 데이터 증강으로 보완 필요
- Nano 모델 특성상 작은 화염 초기 단계의 미감지 위험 존재

### 트레이드오프 요약

```
실시간 추론(78.5ms) + 네트워크 독립 감지  ←→  대형 모델 대비 2~4%p 정확도 손실
```
